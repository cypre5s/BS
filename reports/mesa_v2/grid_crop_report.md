# Image-only grid boundaries and safe cropping

`GridBoundaryDetector` uses local background contrast, directional morphological gap closing/opening, long-run evidence, bidirectional intersections and relative stroke thinness. Each candidate records coordinate, orientation, support, continuity, intersection support, confidence and source method. A candidate is not automatically a real cell boundary: trustworthy outer-frame support is also needed before grid-aware mapping is enabled. Text-like strokes, shadows and unsupported candidates can remain in the audit while being rejected for use.

Full rules, interrupted horizontal/vertical lines, salt noise, edge shadows, partial rules, merged/multi-level headers and irregular row heights are tested. Borderless and incomplete grids return low-confidence candidates/fallbacks without inventing missing rows or columns. The detector is not universally robust to photographs, skew, curved rules or semantic headers; unresolved geometry is expected.

Development inference exposed a double horizontal rule at a header boundary being counted as a tiny additional row. Neighboring rule candidates within the configured four-pixel band are now clustered into one separator before confidence scoring. This uses only image coordinates, never the model's target row count. A dedicated synthetic regression checks the double-rule case. The distance remains configurable: very tightly spaced real rows can be ambiguous, and the canonical grid must still independently match before local fusion is permitted. Logical rows without visible rules are not inferred by adding separators.

`crop_mapping.snap_box` searches outward only. A nearby trustworthy left/top boundary may expand the target toward lower coordinates, and right/bottom toward higher coordinates. Distance is capped. If any required edge lacks support, the entire proposed snap is abandoned. Image-edge targets remain at the image edge, so first/last columns and page margins are not discarded. Horizontal strips retain full height and headers; tiles retain 2×2/3×3 and adaptive grids with overlap.

Metadata includes original/snapped boxes, padding, prepared x/y resize ratios, processed width/height, source table ID, boundary IDs, tile ID, overlap, row/column context and mapping quality. Composite header views use per-piece transforms; a point in a seam has no unique original coordinate unless a piece is explicitly selected. Padding coordinates can be affinely extrapolated for round-trip testing but are not interpreted as observed cell pixels.

Independent synthetic diagnostics (`scripts/mesa/audit_geometry.py`) measured 36 candidate boxes: 144 interior cut boundaries before snapping and zero afterward. All 36 targets retained their full original area. This quantifies behavior on the known geometric fixtures only, not real-image detection accuracy.
